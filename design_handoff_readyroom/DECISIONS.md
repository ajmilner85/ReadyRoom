## Page width (2026-11-05, user feedback)
- App-wide rule: page content sits in `.rr-page` (tokens.css): centred, max 1440px. Applied to Home, Mission Details, Comms, Roster, Events, Debrief (list 600 + details), Training (both tabs), My Training, Dossier, Reports, Settings.
- Exceptions (drag-and-drop workspaces that genuinely use the width): Flight Assignments (columns 320–380px, centred), Mission Support, Kneeboard. Coordination is fullscreen; its four columns cap at 540px and centre.
- Panes whose content is short (Mission Details, Comms, Training, Reports, My Training) end at their content instead of stretching to the window bottom; list/detail workspaces (Roster, Events, Debrief, Dossier) keep full-height panes because their lists scroll.
- Tab bars stay full width (shared across full-width and capped tabs).
- Mission Details panes size to their content (scroll inside only when taller than the window) instead of stretching to the bottom.
- Home Polls / Change Log fill the remaining window height (min 480px) instead of a fixed 560px / 70vh.

## Events page (2026-11-06, user feedback)
- Left pane is one accordion ("Cycles & Events"): pinned Standalone Events, cycles grouped Active / Upcoming / Completed; expanding a cycle selects it and lists its events (In progress / Upcoming / Previous) with publish dots (green published · blue scheduled · hollow draft) and dates; edit/delete appear inline on hover. Only the selected cycle is expanded (events load per cycle). CyclesList/EventsList are no longer used by the page.
- Event Details follows the handoff: status/actions bar (publish status, target squadrons, Send Reminder or Publish/Publish Now, Edit Event), meta grid, then cards in an auto-fit grid: Description, Image, Activities at this event (tinted by kind: syllabus/standalone = info, advanced qualification = accent, exercise = good), Mission Support Roles (event-level, else aggregated from activities), Notifications (initial publication + two reminders with recipient chips), Reference Materials (event + activity refs, deduped). The full-width publish footer is gone.
- Registration/Attendance: Accepted / Tentative / Declined switch with counts; groups (by activity / qualification) are cards in a responsive multi-column grid (min 300px); Mission Support roles as their own cards (filled/required, amber when short).
- Event Details cards have an edit pencil that opens Edit Event on the matching step (EventDialog `initialSection`). The dialog stays unmounted until the Activities flag and any deep-linked step (and, for activity sections, the saved activities) are resolved, with a 2s safety net. When editing, every step is clickable and Save / Save & Update Discord are available from any step.

## Event & Cycle dialogs (2026-11-06)
- Shared building blocks in `events/dialogParts.tsx`: DialogShell (portal, overlay, rr-2xl panel; overlay click only closes when the press started on it; no Escape-to-close, matching the old behaviour so edits aren't lost), DlgCard, SettingRow (whole row toggles), SquadronToggleTile, RolePicker (@role chips in purple tint), UNIT_OPTIONS.
- Event dialog: 1040x900 (capped to viewport), vertical step rail (number, title, description; collapses to a horizontal strip under 760px), content max 760px. Details puts title + cycle on one row, a When card (start, time zone, duration steppers, computed end), description, and four 16:9 image slots in one row (first = header). Reminders are toggle cards with unit segmented control and coloured recipient pills. Publish step opens with a review summary. Creating still walks the steps (Next is primary; Create draft / Create & Publish on the last step).
- Cycle dialog: same shell. Activities flag on: 420px settings column (Details / Options / Reminders / Publication tabs) beside the Activities builder pane; row/activity selection panels are DlgCards. Flag off: 760px with Details / Students / Instructors tabs (enrollment tab internals unchanged). Footer carries validation errors.
- Not restyled yet: the inner editors (EventActivitiesEditor, CycleActivitiesBuilder, CycleActivityConfigPanel, ParticipantBlocksEditor, SupportRoleRequirementsEditor, ReferenceMaterialsInput) and the legacy enrollment lists still use native selects / older styling.

## Second page pass (2026-11-07)
- Dossier: columns are flexible (details 400 / centre 520+ / timeline 380 bases, centre favoured); stats 3+3 or one row of 6 via container query (.rr-stat-grid-6); scope row wraps; tab pills use accent tokens (were legacy orange) here and in the Awards manager.
- Debrief: filters are a compact toolbar (cycle + outcome kit Selects with counts, squadron pills, date range, Filters switch + Clear in the "Missions n / total" header); rows are single-line with mono date and outcome chip; the trailing " Mission" of generated names is hidden (full name in the tooltip). Fixed a load race that let the "all cycles" response overwrite the default-cycle list.
- Reports: per-squadron summary strip (avg attendance %, pilots per event, no shows, snivels) above the chart; chart lines use legibleHex() (canvas-safe legibleColor) so near-black squadron colours are visible; kit Select for the cycle.
- My Training: 360px progress column + roadmap timeline (numbered markers, connector, per-lesson objective bars); unnumbered lessons lead the roadmap.
- PTR: redundant in-card title removed; toolbar = kit cycle Select + student/instructor chips. Badge wrappers lost their legacy -20px offset (PTR grid, grading dialog, cycle enrollment lists), which clipped insignia.
- Kit: Chip accent tone text uses --rr-accent-text (was --rr-accent, unreadable on dark); purple tone uses --rr-purple. Change-log markdown accepts "- " list items and uses text tokens. Settings opens on Appearance when no section is given.

## Settings pass (2026-11-07)
- Settings pages share one header (16/700 title, 12px description, 14x16 padding) and an 860px card column. Events, Mission Debriefing and Mission Preparation are rebuilt on dialogParts (DlgCard, SettingRow, ReminderCard now shared with the Event dialog, NumberStepper, SegmentedControl, kit Select).
- All hand-built 44x24 switches in the app replaced with the kit Toggle; bare "+" add buttons are labelled ghost buttons ("Add status", "Add wing"…); roster settings tables fill the column.
- StyledSelect is now a wrapper over the kit Select (same props). Kit popovers default to z-index 2500 (tooltips 2600) so they open above dialogs; floating roots carry data-rr-floating (AnchoredPopover treats them as inside).
- Native controls still in place get kit styling app-wide: chevron on <select>, no number spinners, accent checkboxes/radios. Remaining native selects: Discord integration, squadron Discord settings, OrgEntityModal, AddEditUnitDialog.
- Icon's color prop is applied via style so token colours resolve; leftover light-theme hexes mapped property-aware to tokens.
- Home fills the viewport: polls/change log row takes the remaining height (min 360px) and scrolls inside each card.
